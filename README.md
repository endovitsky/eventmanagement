# eventmanagement
Сервис для управления мероприятиями на ASP.NET Core Web API.

- Swagger для тестирования доступен по адресу https://{host}:{port}/swagger/index.html
- Добавлен базовый REST API для создания, просмотра, обновления и удаления мероприятий. 

- Для сборки и запуска проекта нужен .NET 9 SDK.
- Откройте консоль в директории \eventmanagement, где находится проект eventmanagement.csproj.
- Выполните команду dotnet build для сборки проекта, затем dotnet run для запуска.
